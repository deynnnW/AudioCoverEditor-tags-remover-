# 🎵 Audio Cover Editor (Смена обложек и тегов песен)

Программа для быстрой смены и удаления встроенных обложек (аватарок) у музыкальных треков, а также очистки от рекламных сайтов (например, `skysound`, `promodj` и др.) для корректного отображения в Яндекс Музыке, ВКонтакте, плеерах Windows, смартфонах и автомагнитолах.

---

## ✨ Возможности

- 🖼️ **Смена обложки**: установите любое изображение (`.jpg`, `.png`, `.webp`, `.bmp`) в качестве обложки трека.
- ❌ **Удаление обложки**: очистите трек от встроенных картинок в 1 клик.
- 🪄 **Очистка от рекламы (SkySound и др.)**: автоматическое удаление промо-ссылок, доменов и водяных знаков из названий и тегов.
- 🚀 **Пакетный режим**: примените одну обложку сразу ко всем добавленным песням или к целой папке.
- 📂 **Drag & Drop**: перетаскивайте аудиофайлы и картинки прямо в окно программы.
- 💾 **Экспорт обложки**: сохранение текущей встроенной картинки из трека в файл.
- 🎶 **Поддержка форматов**: `.mp3` (ID3v2.3/2.4), `.flac`, `.m4a`, `.mp4`, `.ogg`, `.opus`.

---

## 🚀 Запуск программы

### Вариант 1: Запуск готового `.exe` (без установки Python)
Готовый исполняемый файл находится в папке `dist`:
`dist\AudioCoverEditor.exe`

Просто запустите его двойным кликом!

### Вариант 2: Запуск из исходного кода
```bash
pip install -r requirements.txt
python app.py
```

---

## 🛠️ Сборка в `.exe` (если вносились изменения)
Запустите:
```bash
python build.py
```
или дважды кликните по `build.bat`.
