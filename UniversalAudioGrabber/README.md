# ⚡ Universal Audio Grabber & MP3 Extractor

Универсальное и мощное десктопное приложение для загрузки музыки и видео с **YouTube, SoundCloud, VK, TikTok, Bandcamp, Twitch** и более **1000+** других платформ в максимальном качестве (Hi-Res MP3 320kbps / FLAC Lossless / M4A AAC / MP4 Video) с автоматическим вшиванием HD-обложек и метаданных.

---

## 🌟 Ключевые возможности

- 🎵 **Hi-Res Audio 320 kbps**: Извлечение звука в максимальном битрейте.
- 💎 **FLAC Lossless**: Поддержка сохранения звука без потери качества.
- 🖼️ **Авто-вшивание HD-обложек**: Автоматический поиск, конвертация и вшивание оригинальной обложки трека в теги ID3.
- 📋 **Умный буфер обмена (Auto-paste)**: Автоматически подхватывает скопированные ссылки из буфера.
- 🔍 **Предпросмотр перед скачиванием**: Отображает превью видео/трека, автора, длительность и тип (плейлист или сингл).
- 🎬 **Загрузка видео**: Возможность скачать исходный видеоролик в MP4 1080p / 2K / 4K.
- 📁 **Выбор папки**: Удобный выбор директории для сохранения и кнопка мгновенного открытия папки в Проводнике.
- 🖤 **Dark Cyberpunk UI**: Современный тёмный интерфейс на CustomTkinter.
- 📦 **Автономный `.exe`**: Работает на Windows без необходимости устанавливать Python и FFmpeg.

---

## 🛠️ Стек технологий

- **Язык**: Python 3
- **Движок загрузки**: `yt-dlp`
- **Аудио-конвертер**: `imageio-ffmpeg` (встроенный портативный FFmpeg)
- **Теги и обложки**: `mutagen` + `Pillow`
- **Графический интерфейс**: `CustomTkinter`
- **Компиляция**: `PyInstaller`

---

## 🚀 Запуск программы

### 1. Готовый исполняемый файл
Исполняемый файл находится в папке `dist/`:
`dist/UniversalAudioGrabber.exe`

### 2. Запуск из исходного кода
```bash
pip install -r requirements.txt
python universal_grabber.py
```

### 3. Сборка в `.exe`
```bash
python build_grabber.py
```
или просто запустите `build_grabber.bat`.
